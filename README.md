# Code Generator Terminal (Desktop App)

Автономное десктопное приложение для генерации и печати штрихкодов: DataMatrix, QR Code и EAN-128 (GS1-128).

## Возможности
- Одиночный и пакетный режим с поддержкой загрузки из .txt и .csv.
- Сохранение и восстановление сессий генерации через .json.
- Печать PDF (каждый код на отдельном листе A4) и термоэтикеток (57x32, 100x50 и др.).
- Полная автономность (работает оффлайн, при отсутствии локального скрипта подключает CDN).

## Сборка через GitHub
1. Перейдите во вкладку **Actions**.
2. Выберите воркфлоу **Build Windows Application**.
3. Нажмите **Run workflow**.
4. После завершения скачайте собранный архив с `.exe` файлами из блока **Artifacts**.
